# Historical design artifacts

Files below this directory are immutable snapshots retained for design provenance. They are non-normative and may describe behavior that ACS later changed or removed.

Current behavioral and architectural requirements live exclusively in `openspec/specs`; proposed changes live in `openspec/changes`.

## 2026-09-04 original ACS specification

`2026-09-04-original-acs-spec/` is the verbatim specification bundle used to guide the initial ACS implementation. Its internal claims of normative precedence apply only to that historical proposal. Do not update it in place; record current decisions through OpenSpec instead.
